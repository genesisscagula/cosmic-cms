# 100 New Sparks Audit — Batch 3: Image-card / Default Content Balance

Scope: all 100 new Expansion Sparks.

Changes:
- Enriched the sparse Team defaults with one-sentence role descriptions while preserving names and functional labels.
- Enriched Gallery defaults with more useful editorial captions.
- Enriched Location defaults so address/hours cards also carry enough supporting context to balance taller visual cards.
- Reworked Testimonials Image Wall so its split cards intentionally use both halves: image on one side, full testimonial hierarchy on the other.
- On mobile, testimonial wall cards stack naturally.
- Blurred / washed mosaic-style cards now anchor their copy in a subtle lower content panel so text feels intentional instead of floating in a large empty image field.

Design rule preserved:
Do not force equal-height generic grids. Keep the premium asymmetric/editorial character and add only enough default content/structure to prevent accidental empty composition.
