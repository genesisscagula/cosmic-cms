# Cosmic CMS v2.7.4.1 — Blog Spark Layout Picker

## Included

- Section-specific **Change Spark** options for all four Blog section groups.
- Blog Mini Header shows only its three free Mini Header Sparks.
- Blog Cards shows only its three free card Sparks.
- Blog Newsletter shows only its three free newsletter Sparks.
- Blog Latest Resources shows only its three free resource Sparks.
- The currently active layout is highlighted and labelled **Current**.
- Changing a Blog Spark updates only `layout_variant`, preserving the section's content, theme, and position.
- Selections remain in the page block payload and persist through the existing Builder save flow.
- Existing ownership-based layout switching remains unchanged for non-Blog blocks.
