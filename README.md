# Cosmic CMS

AI-first website builder powered by Laravel and React.

Generate production-ready websites from a single prompt.

---

## Vision

Traditional CMS:

User → Design → Edit → Publish

Cosmic CMS:

Business Idea

↓

AI Planner

↓

Content Generator

↓

Block Registry

↓

Compiler

↓

Static HTML

↓

Deploy

---

## Philosophy

The user owns the content.

The CMS owns the design.

Users describe their business.

Cosmic CMS composes the website.

---

## Features

- 🤖 AI-first website generation
- 🧩 Registry-driven block architecture
- 🎨 Theme system
- ⚡ Static HTML compiler
- 🔄 Reusable React blocks
- 🚀 One-click deployment (planned)
